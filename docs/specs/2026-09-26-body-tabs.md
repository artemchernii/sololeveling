# Body in tabs — DID ALL and bulk remove (26 Sep)

Artem, after the rebuild: "order is still confusing. Maybe we should do
tabs … we want to bulk DID and in DONE we want to bulk undo. Its kinda
nice but hard to use now." He took the three recommended picks ("go with
your picks").

## What gets built

- **Hero stays on top**, above the tabs, as it is.
- **Tabs: Today · Programs · History**, in the Languages tab style. The
  tab lives in the URL (`?tab=`), so a refresh keeps it. Today is the default.
- **Today** — Log today (the five buttons, unchanged); the next-up
  routine open; the others folded; "added by you" last.
- **DID ALL** on every open routine card. One tap writes an `exercise` log
  for each exercise of that day not yet ticked today, and one `workout`
  (the session the Today tile counts) unless that kind's session is already
  logged today. The button says it logs the session, so the session is his
  claim, not an inference. Undo takes the whole tap back.
- **Programs** — the library, unchanged.
- **History** — the Done list; a **Select** mode puts a checkbox on each
  row and "select day" on each day; **Remove selected** deletes them in one
  write.

## Files

- `convex/drills.ts` — `didDay({ dayId, todayStart })` → the log ids
  written.
- `convex/logs.ts` — `removeMany({ logIds })`, all-or-nothing: another
  owner's row refuses the whole call. Weight rows take their snapshot with
  them, as `remove` does.
- `src/lib/body/library.ts` — `SESSION_LABEL` moves here, shared by the
  session buttons and `didDay`.
- `src/components/track/DidButton.tsx` — undo takes back a group.
- `src/routes/_app/body.tsx`, `src/components/body/*` — tabs, DID ALL,
  select mode.
- Tests: `convex/drills.test.ts`, `convex/logs.test.ts`.

## Done when

On Body, open Today, press DID ALL on Lower-back mobility: every exercise
ticks, the Mobility session shows ×1 and the hero lights today. Undo clears
all of it. In History, Select → select day → Remove selected empties the
day. Refresh on History stays on History.
