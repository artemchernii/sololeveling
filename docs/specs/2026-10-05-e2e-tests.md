# Browser tests on mock data — never on his account

**Why (5 Oct).** "We fix one thing and break other. But I don't want to
mess up my account data." Unit tests (1,128) check functions; nothing
checks a screen end to end — drop a file, press confirm, see it land.
Today I could not press confirm in the pane without writing into his
real Revolut. So the screens shipped unseen and broke.

## What gets built

1. **A separate backend for tests.** A local Convex backend on this Mac
   (`convex dev --local`), its own empty database, started and thrown
   away by the test run. His dev deployment and prod are never touched,
   and it costs nothing on his Convex plan.
2. **A test user.** A second user on the same Clerk dev instance
   (`…+clerk_test@…`, fixed code, no real email). Playwright signs it in
   with `@clerk/testing` — no clicking through Google.
3. **Mock data, test DB only.** `convex/e2e.ts` with `seed` / `reset`:
   accounts like his (Revolut EUR+USD, ActivoBank, BPI, Cash, TR, 212),
   balances 8 days old, a few September rows. It refuses to run unless
   the deployment has `E2E=1`, which only the local test backend has.
4. **No paid AI in tests.** The Revolut CSV column map is seeded, so a
   CSV is read by code alone. PDFs and screenshots wait for v2.
5. **The first tests: today's breakages.**
   - drop the October CSV → "2 new payments…", times, logos, CSV badge
   - confirm → the tick lands; Revolut EUR and USD both fresh; check-in clears
   - "still the same" → turns green, "saved today", sheet closes
   - a CSV with a header the app hasn't seen → no 400
     Each test saves a screenshot to `e2e/screens/` so I look before you do.
6. **`pnpm e2e`** runs it all: starts the local backend + the app on
   :3200, seeds, tests, stops. Run before every PR.

**Files:** `playwright.config.ts`, `e2e/*.spec.ts`, `e2e/fixtures/*.csv`,
`convex/e2e.ts`, `package.json` scripts, `.env.e2e` (gitignored).

**New dependencies:** `@playwright/test` (drives a real browser);
`@clerk/testing` (signs the test user in without the Google screen).

## Done when

`pnpm e2e` passes locally with the five tests above, his dev data is
unchanged before and after (row counts compared), and the screenshots are
in the PR.
