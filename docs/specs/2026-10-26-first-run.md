# First run (R8 · S2)

Journey: a friend signs up on workers.dev and opens the app for the first
time. One System window asks the language they are learning (Portuguese,
English, German, or NONE); the timezone is read from the device, shown, not
asked. GO → saving → saved → the window closes into Today, which greets
them by their Clerk first name, or HUNTER when there is none. Once only.
Artem never sees it. His words, 26 Oct: "yes, language only; HUNTER
instead of 'you'", then "go on the one-step first run".

Mockup: `design/firstrun-mockup/index.html` (launch `firstrun`, :3951).

## Screens and functions

- `profiles` table: `ownerId`, `timezone`, `firstRunAt`; index `by_owner`.
- `convex/profiles.ts`
  - `mine` query → `{ needsFirstRun, timezone }`. `needsFirstRun` is true
    when there is no profile row **and** no log row — a person who has
    logged anything (Artem, on dev and prod) is never asked, so his data
    needs no write.
  - `finishFirstRun({ lang, timezone })` mutation: refuses an unknown
    language or zone; adds the language area the way `areas.addLanguage`
    does (`addLanguageFor`, shared); writes or updates the profile row.
  - `zoneFor(ctx, ownerId)`: the profile's zone, else `OWNER_ZONE`.
- Calendar reminders (`convex/events.ts`) and the bell's day count
  (`convex/push.ts`) read the person's zone through `zoneFor`.
- `src/components/shell/FirstRun.tsx`, shown by `_app.tsx` when
  `needsFirstRun`.
- Today's greeting falls back to HUNTER (`dashboard.tsx`).

## Scenarios

- F1 a new person → the window, four cards, GO disabled until one is
  picked, TIMEZONE with the device's zone → pick English → GO →
  SAVING at once → ✓ SAVED → closes → Today says their name or HUNTER,
  and Languages has English.
- F2 NONE → GO → no language area is made; the window does not return on
  reload.
- F3 a person with a log and no profile (Artem) → no window.
- Refusals (convex-test): unknown language, unknown zone, signed out.
  One owner's profile never answers for another.

## Data

No numbers. A profile row is state the person chose; the zone is read from
the device's `Intl` and stored once.

## Out of scope

Rooms switched off for invited people, the Today tiles that are his
(S3). Changing language or zone later goes through Languages and a future
Settings row. The evening CLOSE push and money alerts stay on Lisbon: they
are Finances, which invited people do not get.
